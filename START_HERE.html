🚀 Artillery Game - Modern Scorched Earth

⚠️ Important: This game uses ES6 JavaScript modules and requires a local web server to run. You cannot simply open index.html directly in your browser due to CORS (Cross-Origin Resource Sharing) security restrictions.

🎮 How to Start the Game

Option 1: Automatic (Easiest)

1 Linux/Mac Users: 
./start.sh
1 Windows Users: 
start.bat
Or double-click start.bat in File Explorer
2 Open your browser to: 
http://localhost:8080
✅ The game should now load with the menu visible!

Option 2: Manual Server Start

If the automatic scripts don't work, manually start a server:

Python 3 (Most Common): 
python3 -m http.server 8080
Python 2: 
python -m SimpleHTTPServer 8080
Node.js: 
npx http-server -p 8080
PHP: 
php -S localhost:8080

❓ Troubleshooting

Error: "No web server found"

Install one of the following:

  • Python 3: python.org/downloads
  • Node.js: nodejs.org
  • PHP: php.net/downloads

Port 8080 already in use?

Change the port number to something else (e.g., 8000, 3000, 5000):

python3 -m http.server 3000

Then open: http://localhost:3000

Menu still not showing?

Open browser console (F12) and check for errors. Look for:

  • Red error messages
  • Failed to load resources
  • CORS errors

🎯 Game Controls

Mouse (Primary):

  • Click and drag on your tank to aim
  • Release to fire

Keyboard:

  • Arrow Keys / A-D: Adjust angle
  • Spacebar: Fire with 50% power
  • 1-4: Select weapon
